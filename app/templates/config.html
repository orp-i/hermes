说明

本页是唯一需要修改配置的地方。保存后写入容器内 /config/hermes.yaml（宿主机 ./config/hermes.yaml）：Web 层在下一次请求刷新，Agent、搜索后端与 LLM 网关按文件 mtime 重新读取，模型、密钥和路由的改动都不需要重启容器。

访问码在首次启动时随机生成并写入日志，可在下方修改。普通用户登录后仍需管理员在设备管理页批准设备。

使用建议

  • 只配置一个模型时，保留 default provider，填写 base_url、api_key 和 default_model。
  • 配置多个模型时，在 Provider 配置 YAML 中增加 provider，并在 chat/code/plan/long_context 映射里填写 provider ID。
  • 需要联网搜索时，配置 Exa 或 Firecrawl API key，并在对话中明确要求“搜索/最新/来源”。
  • 修改 API key、provider 和路由后，下一次模型请求会自动使用新配置；修改容器环境变量仍需重启对应容器。
  • 密钥只需填在本页。环境变量与早期的 model.env 仍作为兜底读取，优先级低于本页。
